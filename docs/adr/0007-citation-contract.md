# Every claim in a report must carry a verifiable citation

The Code Navigator returns structured Findings. Each Finding cites at least one `path:line-range` at the analysed commit, optionally naming the symbol it points into. The Report Writer may only rephrase and combine Findings. Citations are validated deterministically against the Lines read, the lines of the Snapshot the model was shown in that Run: every cited line was shown, and the claimed symbol appears there. So a model can't cite code it never saw, even if the lines exist. Invalid Citations are dropped before the Report is written and recorded in the Run log. The same check is an eval metric (citation validity).
