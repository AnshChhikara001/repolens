# Every claim in a report must carry a verifiable citation

Specialists return structured findings. Each finding cites either a `path:line-range` at the analysed commit or a commit/PR/issue number. Quantitative facts (churn, authorship, vulnerability counts) come from tool output, never from model text. The Report Writer may only rephrase and combine findings. Citations are validated deterministically against the lines read, the lines of the snapshot the model was shown in that run: every cited line was shown, and the claimed symbol appears there. So a model can't cite code it never saw, even if the lines exist. Invalid citations are dropped before the report is returned. The same check is the primary eval metric.
